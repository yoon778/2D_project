# 2D_project

2026년 2D게임프로그래밍 학기 프로젝트입니다. Python과 pico2d로 창작 2D 게임을 개발합니다.

게임은 **그림자 배달(가제)** · 왼손 몸 앞에 택배, 오른손에 야구방망이를 든 배달원이 좀비와 싸우거나 피하며 배달하는 게임

**새 방향(2026-11-03): 고정 사선 3/4의 2.5D** · 참고 그림처럼 세운 캐릭터의 다리·발과 건물 앞뒤가 보이는 화면
Python + pico2d의 2D 스프라이트를 사용하며 지상 한 층에서 진행 · 첫 캐릭터는 4방향 자세와 최소 모션부터 제작
발 접지점 기준 배치·깊이 정렬·지면 조준 변환·건물 가림을 먼저 확인하고, 8방향과 세부 모션은 기본판 안정 후 확장

최종 기획은 마우스 방향 손전등 안만 보이고, 바깥은 완전 암흑과 희미한 건물 윤곽으로 표현 · 보이지 않는 좀비의 소리는 들림
공격 소음 조사·추격·수색도 목표 규칙에 포함 · 발판 상자·옥상 기능은 삭제

현재 실행본은 **기존 수직 탑뷰 프로토타입** · 새 2.5D 표현은 아직 미구현
기존 주인공 이미지와 임시 도형 맵·좀비에 이동·조준·근접 전투·배달·승패·재시작 연결
손전등 암흑 시야·건물 가림·소음 조사·건물 우회·스태미나 달리기·5타 전투 확인 가능
좀비 타격은 밀림 없이 상체 움찔·제자리 경직, 경직 중 이동·접촉 공격 중단
손전등 밖·벽 뒤 좀비 발소리·신음도 들리고 가까울수록 음량 증가
좀비 시야각·순찰·좀비/맵 이미지는 후속 단계

첫 완성 목표는 **지도 1개·야구방망이 1종·좀비 1마리·배달 1건** · 임시 그래픽과 효과음으로 한 판을 먼저 작동시키고 플레이하며 확장
예상 최종 마감은 12월 둘째 주, 자체 완성 목표는 12월 6일

교수 추가 공지에 따라 AI 이미지 생성으로 캐릭터를 직접 준비하는 방식을 권장하며, 기존 에셋·스프라이트·애니메이션 사용도 허용합니다. 기존 그래픽 사용 시에는 독창적인 규칙·시스템 등 기획적 차별화가 분명해야 합니다. 상세 조건은 `PRD.md`에 정리했습니다.
