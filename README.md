# Dead Route

게임명: **Dead Route (데드 루트)**

작은 골목에서 좀보이드식 거리 조절과 소음 위험을 겪으며 택배를 배달하는 Python/pico2d 게임입니다.

## 새 시작 기준 — 2026-11-03

- 고정 사선 3/4의 2.5D, 왼손 몸 앞 택배·오른손 방망이·가슴등
- 첫 범위는 지도 1개·좀비 1마리·방망이 1종·배달 1건
- 현재는 정리와 개발 준비 단계이며 새 2.5D 실행본은 아직 없습니다.
