# 게임 후보 3종 간단 기획서

작성일: 2026-10-30

Python과 pico2d로 개발할 게임 후보입니다. 아래 조작법과 규모는 비교를 위한 제안이며, 최종 선택 전의 초안입니다.

**선택 결과(2026-10-31):** 사용자가 3번 그림자 배달을 탑뷰·총 없는 좀비 회피·손전등 시야가 있는 게임으로 선택했습니다. 이 문서는 선택 전 후보 비교 기록이며, 변경된 규칙과 현재 기획은 [PRD.md](PRD.md)를 기준으로 확인합니다.

**현재 방향(2026-11-03, 이전 선택을 대체):** 그림자 배달은 사용자 참고 그림 같은 고정 사선 3/4의 2.5D 전투·배달 게임으로 변경했습니다. 왼손 몸 앞 택배·오른손 야구방망이, 마우스 방향 손전등, 시야 밖 청각과 소음 조사 규칙을 사용합니다. 첫 범위는 지도 1개·좀비 1마리·배달 1건입니다. 발판 상자·옥상·높이 이동은 제외합니다. 아래 세 후보의 원래 설명은 비교 이력으로 보존합니다.

## 1. 자석 청소부

**한 줄 소개:** 고철을 끌어모아 무기로 사용하는 청소 로봇의 생존 액션 게임입니다.

- **화면과 상황:** 위에서 내려다보는 폐기장입니다. 청소 로봇 주변으로 적 드론이 접근하고 바닥에는 고철이 흩어져 있습니다.
- **목표와 실패:** 고철로 적을 처치하며 3분 동안 생존합니다. 체력이 모두 소진되면 실패합니다.
- **조작:** WASD로 이동하고 마우스로 조준합니다. 마우스 왼쪽 버튼을 누르면 주변 고철을 모으고, 놓으면 모은 고철을 조준 방향으로 발사합니다.
- **진행:** 고철 수집 → 적의 접근을 피하기 → 발사 시점 선택 → 적 처치 → 다시 고철 수집을 반복합니다. 고철은 바닥에 주기적으로 나타나 탄환이 없는 상태에서도 다시 모을 수 있습니다.
- **핵심 재미:** 고철을 많이 모으면 한 번에 강하게 공격하지만 이동이 느려집니다. 적게 모아 자주 공격할지, 위험을 감수하고 많이 모을지 선택합니다.
- **최소 구현 범위:** 고정 화면 맵 1개, 플레이어 1종, 적 2종, 고철 수집·발사, 체력, 3분 타이머, 결과 점수입니다.
- **개발 초점:** 고철이 모이고 발사되는 움직임과 이동 감속의 조절입니다. 고철 보유량에는 상한을 둡니다.

**플레이 예시:** 고철을 잔뜩 모아 적 무리를 한 번에 처리하려다가 느려진 이동 때문에 포위됩니다. 일부만 모아 빠르게 발사하고 이동하는 전략으로 바꿉니다.

## 2. 반사 경비원

**한 줄 소개:** 적의 탄환을 방패로 되돌려 싸우는 조준·타이밍 액션 게임입니다.

- **화면과 상황:** 경비원은 화면 중앙에서 자리를 지킵니다. 주변에 등장한 적 포탑이 발사 예고 후 탄환을 쏩니다.
- **목표와 실패:** 반송한 탄환으로 적을 처치하며 5개 웨이브를 완료합니다. 방어하지 못한 탄환에 맞아 체력이 모두 소진되면 실패합니다.
- **조작:** 마우스로 방패 방향을 정하고 왼쪽 버튼으로 잠깐 방패를 활성화합니다. 사용 후에는 짧은 재사용 대기시간이 있습니다.
- **진행:** 적의 발사 예고 확인 → 날아오는 탄환 추적 → 방향 조준 → 닿기 직전 방패 사용 → 반송 탄환으로 적 처치를 반복합니다.
- **핵심 재미:** 직접 탄환을 발사하지 않고 적의 공격을 공격 수단으로 사용합니다. 여러 방향의 탄환 중 무엇을 먼저 막을지 판단하는 재미가 있습니다.
- **최소 구현 범위:** 고정 화면 맵 1개, 방향 전환이 가능한 방패, 적 포탑 2종, 탄환, 체력, 5개 웨이브, 결과 화면입니다.
- **개발 초점:** 방패 활성 시간, 탄환 속도, 공격 예고의 조절입니다. 정면에서 막은 탄환을 조준 방향으로 되돌리는 단순 규칙을 사용합니다.

**플레이 예시:** 오른쪽에서 날아오는 탄환을 되돌려 포탑을 파괴합니다. 바로 위쪽 탄환이 이어져 방패를 돌리지만, 너무 일찍 사용하면 탄환이 도착하기 전에 방패가 꺼집니다.

## 3. 그림자 배달

**한 줄 소개:** 움직이는 감시등을 피해 그림자 사이로 물건을 배달하는 잠입·경로 선택 게임입니다.

- **화면과 상황:** 위에서 내려다보는 작은 밤거리입니다. 벽과 골목, 수령 지점, 배달 목적지, 정해진 경로로 움직이는 감시등이 있습니다.
- **목표와 실패:** 제한시간 안에 목적지 3곳에 물건을 배달합니다. 발각 게이지가 가득 차거나 시간이 끝나면 실패합니다.
- **조작:** WASD로 이동하고 E로 물건을 받거나 전달합니다. 한 번에 물건 하나를 운반합니다.
- **진행:** 물건 수령 → 감시등의 이동 관찰 → 배달 경로 선택 → 그림자에서 대기하거나 밝은 구간 통과 → 목적지 전달을 반복합니다.
- **핵심 재미:** 짧지만 빛에 노출되는 길과 길지만 안전한 그림자 길을 선택합니다. 빛에 머물면 발각 게이지가 오르고 그림자에서는 내려갑니다. 감시등이 지나갈 때까지 기다리면 안전하지만 배달 시간이 줄어듭니다.
- **최소 구현 범위:** 고정 화면 지도 1개, 수령 지점 1곳, 배달 목적지 3곳, 감시등 2개, 벽 충돌, 발각 게이지, 제한시간입니다.
- **개발 초점:** 안전한 길과 빠른 길이 모두 의미 있도록 지도를 배치하는 작업입니다. 감시는 미리 정한 조명 영역으로 판정해 빛과 그림자의 경계를 화면에서 분명히 보여줍니다.

**플레이 예시:** 목적지는 바로 건너편이지만 감시등이 길을 비추고 있습니다. 남은 시간이 충분하면 뒤쪽 골목으로 돌아가고, 시간이 부족하면 발각 게이지에 여유가 있는지 보고 밝은 길을 빠르게 가로지릅니다.

| 반사 경비원 | 방향과 타이밍을 맞춰 반격 | 탄환과 방패의 반응 시간 |

특징이 선명한 액션을 원하면 자석 청소부, 움직임과 맵 구성을 작게 시작하려면 반사 경비원, 관찰과 경로 판단을 좋아하면 그림자 배달을 추천합니다.
