# 임시 리소스

## 시점 전환에 따른 리소스 상태 — 2026-11-03

새 기획은 인물의 앞·옆·등과 다리가 보이는 **2.5D 고정 사선 시점**이며 아직 게임에 구현하지 않았다. 아래 아틀라스·clip·표시 규격·검수 내용은 **이전 수직 탑뷰 시제품 기록**이다. 원본 PNG·프롬프트 원문·해시는 보존하고, 해당 아틀라스는 새 시점의 캐릭터 교체 대상이다.

새 캐릭터에는 발바닥 접지점 피벗과 초판 4방향·후속 8방향 원본이 필요하다. 조준각은 연속 유지하되 이미지 전체 360도 회전은 사용하지 않는다. 기존 원본을 기울이거나 돌리는 것만으로 새 시점용 스프라이트를 대체하지 않는다. 새 원본은 아직 제작하지 않았다.

왼손 몸 앞 택배·오른손 방망이·가슴등은 유지한다. 참고 이미지의 주황 가방은 분위기 참고이며 인벤토리 규칙 변경이 아니다. 앞뒤 깊이·가림과 지면 손전등 마스크·세운 스프라이트 표시도 후속 구현 대상이다.

## 이전 시제품에서 사용하는 리소스

- 주인공: 아래 아틀라스를 부위별로 잘라 표시. 좀비·맵·효과는 기존 pico2d 도형 유지.
- audio/attack.wav, hit.wav, hurt.wav, zombie_step.wav, zombie_groan.wav: 이 프로젝트용으로 합성한 임시 효과음, 외부 음원 사용 없음
- 글꼴: 설치한 pico2d 패키지의 ConsolaMalgun.ttf 사용, 별도 폰트 복사 없음

### 이전 시제품 적용 clip·피벗·표시 규격

clip은 PNG 좌상단 기준 `(x,y,w,h)`, 피벗은 해당 clip의 좌상단 기준 `(x,y)`다. 표시 크기는 가로폭이며 종횡비를 유지한다. pico2d 호출 시 `bottom=1024-y-h`로 변환하고, 이미지 중심과 피벗의 차이를 회전·배율에 맞춰 보정한다.

| 부위 | clip | 피벗 | 표시 가로폭 |
| --- | --- | --- | --- |
| 몸·머리·가슴등 | (102,91,330,351) | (154,165) | 36px |
| 팔·손 | (605,201,326,132) | 어깨 (32,59), 손 (280,63) | 22px |
| 부츠 | (1136,193,294,153) | (147,76) | 12px |
| 택배 | (126,653,264,225) | (132,112) | 20px |
| 방망이 | (557,720,423,84) | 손잡이 (80,42) | 56px |

- 모든 부위는 오른쪽이 전방이며 좌우 반사 없이 `player.angle`로 회전한다. 몸의 논리 중심과 충돌 반경은 변경하지 않는다.
- 몸 기준 `(전방,왼쪽)` 좌표: 왼쪽 어깨 (0,13), 오른쪽 어깨 (2,-14), 발 (-16,±12). 택배는 왼손에서 전방 10px·오른쪽 2px에 두고, 방망이 손잡이는 오른손에 고정한다.
- 보행 위상은 실제 이동 거리에만 따라 증가한다. 한 주기 이동 거리는 걷기·공격 이동 40px, 달리기 44px이며 발은 ±3px 교대 이동한다. 새 Actor 또는 시간 역행 시 캐시를 초기화한다.
- 준비·타격·회복은 기존 `attack_elapsed`, 타격 0.18초·전체 0.6초에 맞춘다. 피격은 렌더 위치만 잠깐 움찔하고 무적시간 동안 점멸하며, 논리 좌표·공격·소음 사건을 변경하지 않는다.
- clip은 알파 16 초과 실체 경계에 약 2px 여백을 둔 후보를 적용했다. clip 내부의 저알파 잔여까지 제거한 것은 아니다. 실제 SDL의 검정 배경·원래 표시 크기와 3배 확대 공격 자세에서 눈에 띄는 사각 광륜은 관찰되지 않았다.
- 확인 범위: 최소 SDL 렌더·게임 상태 비변조·반복 close·육안 자세 확인. 검정 배경의 3배 확대본에서 정지·걷기·달리기 각각 0.06초 간격의 4프레임을 비교하고 발 앵커를 뒤·바깥쪽으로 보정했다. 전체 회귀와 자원별 해제 추적, 실제 조작감·출력 장치 청취는 지휘의 후속 검증 대상이다.
