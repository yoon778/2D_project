# 8방향 원화 일관성 후보 · R1-C8-C1

승인한 `../front-right-idle-64.png` 한 장을 정체성 기준으로 사용한 8방향 정지 턴어라운드
생성 도구는 built-in image_gen.imagegen. 정확한 생성/교정 지시는 [generation-prompts.json](generation-prompts.json)

- 같은 카메라 높이·정사영·조명·체형·모자/머리 비율·어깨/허리/골반 가이드
- 순서: 앞·앞오른쪽·오른쪽·뒤오른쪽 / 뒤·뒤왼쪽·왼쪽·앞왼쪽
- v1은 원화 높이387~407px로 반려. v2는 키 차이를 줄였지만 오른쪽 부츠보다 방망이 끝이 낮아 등록 기준 오류 발견
- v3은 같은 원화의 오른쪽 부츠/방망이 끝을 imagegen으로 교정하고, 해당 셀만 조립해 다른7방향의 원본RGBA를 보존
- 최종 공통1/6 배율에서 신체63~65px, 기준64±1px. 소품과 몸의 분리 자동 마스크는 없으므로 실제 모자/부츠는 시각 검수도 병행
- 전체 방향에 같은 등방 배율 사용. 방향별 세로 늘림/눌림 금지. 등록은 위치 평행이동만 허용
- 80px 셀·발바닥y72·다리축x40, 고정24색 팔레트·알파0/255. 실제 부츠 기준은 `body-anchors.json`, 방망이 끝이나 전체alpha로 발점을 계산하지 않음
- 원화의 낮은 알파 광륜은 임계값200으로 제거. 후보 PNG는 `turnaround-idle-64-v3.png`
- `turnaround-review.json`의 실루엣 높이는 소품 포함 참고 값. 검수자가 모자/몸/부츠 및 방망이 끝의 상대 위치를 별도 확인

준비/재현: 프로젝트의 기존 Sharp 환경에서 `prepare-guide.cjs` → 원화 생성 → `assemble-right-correction.cjs` → `compile-turnaround.cjs`. 각 스크립트는 이 폴더에 있으며 프로젝트 루트에서 `node art/player/style-studies/eight-direction-consistency/스크립트명` 실행

사용자가 이 원화를 기준으로8방향 보행 제작·게임 적용을 지시해 원화 승인 수신
R1-C8-WALK에서 같은 체형 기준으로 보행을 연결하고 방향 전환 때 크기·발점·장비가 유지되는지 확인

지휘1차 검수: 두 개발 채팅·독립 수치/시각 검토에서 필수 수정 미발견. v3 오른쪽은 실제 부츠색이y72에 남고 모자y10 기준 신체63px 확인. 다른7방향의 원화/컴파일 셀은 v2와 동일. 사용자 승인 뒤 보행 적용본의2차 확인으로 이어짐
