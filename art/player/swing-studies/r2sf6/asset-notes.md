# R2-SF6 앞오른쪽 정지 스윙 시안

`poses.png`는 투명 576×96px 아틀라스. 왼쪽부터 정지, 준비, 골반·어깨 회전, 한 손 타격, 관성 통과, 낮은 회수. 96px 셀마다 발점 (48,80).

- 첫 장은 승인된 앞오른쪽 idle 픽셀. 나머지 다섯 장은 같은 팔레트와 원본 부츠 밑창으로 제작. 왼손은 택배, 오른손은 방망이 유지
- PixelLab 기존 64×64 배달원, South-East, Custom V3, 기존 idle 유지로 6프레임 생성 요청. 내려받은 GIF는 92×92px 프레임 7장
- PixelLab 원본 5장의 벌어진 무릎과 몸 뒤로 빠진 손을 준비 자세에 반영. 원본 7장의 손 (43,57) 부근에서 방망이 끝 (66,66) 부근으로 내려가는 방향을 타격에 반영. 최종 그립 (67,45), 끝 (85,52)
- 원본의 보행성 발 이동 대신 승인 부츠 위치에서 무릎을 굽혀 체중 이동 표현. 생성 결과의 자세를 참조해 픽셀을 다시 그렸으므로 직접 복사된 PixelLab 픽셀은 0개
- 준비 이후 방망이 끝 이동 33.4, 32.2, 30.5, 26.3px. 타격·통과는 방망이가 화면 오른쪽 아래로 내려간 뒤 몸 앞으로 이어짐

- 재생성 `node art/player/swing-studies/r2sf6/bake.cjs`
- 검수 `node art/player/swing-studies/r2sf6/bake.cjs --check`

원본 GIF와 비교 이미지는 `output/review/R2-SF6-art/`. 이 아틀라스는 180/240ms 비교용이며 시간값은 포함하지 않음.
