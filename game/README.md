# 그림자 배달 첫 프로토타입

## 현재 기획과 실행본 상태 — 2026-11-03

기획은 참고 이미지처럼 인물의 앞·옆·등과 다리가 보이는 **2.5D 고정 사선 시점**으로 변경했다. 현재 실행본은 **이전 수직 탑뷰 시제품**이며, 아래 실행·조작·구현·검증 내용은 그 시제품의 기록이다. 새 2.5D 렌더와 캐릭터는 아직 구현하지 않았다.

- 새 캐릭터는 발바닥 접지점을 피벗으로 삼고 초판 4방향, 후속 8방향을 준비한다. 조준각은 독립적으로 연속 유지하며 이미지 전체를 360도 회전하지 않는다.
- 앞뒤 깊이·가림과 손전등의 지면 마스크·세운 캐릭터 스프라이트 표시를 분리하는 렌더 구성이 필요하다.
- 왼손으로 몸 앞의 택배를 들고 오른손 방망이·가슴 부착등을 유지한다. 참고 그림의 주황 가방은 분위기 참고이며 새 인벤토리 기능이 아니다.
- 현재 아틀라스·발 배치·360도 회전과 기존 렌더 검증 결과는 이전 시점용이다. 기존 원본·소스·검증 이력은 보존하고, 2.5D용 그래픽과 렌더는 후속 작업에서 교체한다.

## 이전 수직 탑뷰 시제품 개요

탑뷰 주인공 이미지와 임시 도형 맵·좀비로 이동·조준·전투 감각을 확인하는 실행본
주인공은 몸·팔·발·택배·방망이 아틀라스를 조립하고, 보행·공격은 코드 모션으로 연결
좀비·맵 정식 이미지와 별도 보행 프레임은 이후 순차 적용

## 실행

프로젝트 루트에서 한 번 설치:

    py -3.13 -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r game/requirements.txt

이후 game/실행.bat 더블클릭 또는 프로젝트 루트에서 실행:

    .\.venv\Scripts\python.exe game/main.py

## 조작

| 입력 | 동작 |
| --- | --- |
| Enter | 게임 시작 |
| WASD | 천천히 걷기, 좀비와 같은 속도 |
| Shift + WASD | 1.5배 달리기, 스태미나 소모 |
| 마우스 | 바라보는 방향 |
| 왼쪽 클릭 | 방망이 공격 |
| E | 택배 수령·배달 |
| R | 성공·실패 화면에서 재시작 |
| Esc | 종료 |

시작 위치에서 E로 택배를 받고 오른쪽 위 목적지까지 이동해 E로 전달
좀비는 230px 안에서 벽으로 가려지지 않은 플레이어를 추격
벽 뒤에서도 걷기·달리기·헛스윙 소음을 듣고, 발생 위치까지 건물을 돌아가 조사
보이지 않는 플레이어의 현재 위치를 계속 추적하지 않으며, 조사 후 짧게 수색하고 대기
걷기와 좀비는 90px/s, 달리기 135px/s, 공격 중 이동 60px/s
스태미나 100, 달리기 초당 25 소모·그 외 초당 20 회복, 소진 시 25까지 회복 후 다시 달리기 가능
Shift만 누르거나 벽에 막혀 움직이지 않으면 스태미나 소모·발소리 사건 없음
좀비 체력 5, 유효 타격 5번으로 처치 · ?는 조사·수색, !는 추격
공격 중에는 이동이 느려지고, 한 공격당 피해 한 번만 발생
명중한 좀비는 밀리지 않고 상체가 움찔한 뒤 제자리에서 0.4초 경직
경직 중 이동·접촉 피해 중단, 종료 후 추격 재개
체력 0이면 실패, 배달 완료면 성공
게임 창을 벗어나면 진행을 일시 정지

## 구현 범위

- 주인공 아틀라스 1장과 기본 이동·공격·피격 모션, 몸 앞 왼손 택배·오른손 방망이
- 건물 충돌, 근접 타격·피해·제자리 경직·피격 무적·사망
- 좀비 1마리, 택배 1건, 성공·실패·전체 초기화
- 벽 뒤 소음 조사·마지막 위치 기억·건물 우회·도착 후 수색
- 걷기·달리기 소음 판정, 스태미나·소진 회복 HUD
- 합성한 임시 휘두르기·명중·피격·좀비 발소리·신음 효과음

손전등은 마우스 방향 80도·340px 범위, 건물이 빛을 차단
바깥은 완전 검정이며 건물 윤곽만 희미하게 표시, 플레이어·HUD·조준점은 유지
좀비·적 체력·상태·배달 표식·효과는 같은 시야 마스크로 가림
E 수령·배달도 거리와 같은 시야 판정을 통과해야 가능
좀비의 제한 시야각·순찰은 후속 단계
발소리·공격 파문은 소음 발생의 임시 표현이며 좀비 청각 판정과 연결
걷기 80px·달리기 260px·공격 480px 반경, 효과음 재생과 AI 감지는 별개
좀비는 실제 32px 이동마다 발소리, 첫 1초 후 약 3.2초 간격으로 신음 재생
청취 반경 520px, 가까울수록 크게 들리며 빛 밖·벽 뒤에서도 동일 적용
포커스 상실·승패·좀비 사망·재시작 때 남은 좀비 소리 정지
플레이어 걷기·달리기의 실제 발소리 리소스는 아직 미적용

## 확인

    .\.venv\Scripts\python.exe -m unittest discover -s game/tests -v

    .\.venv\Scripts\python.exe game/tests/player_asset_smoke.py

결과는 tmp/player-asset-qa/result.json과 PNG에 저장, 손·장비 배치와 원본 품질은 이미지 검토 필요
주인공 적용 검증은 렌더 29장·게임 상태 보존·재시작·자원 해제 통과, 지휘가 양손·택배 앞 배치·공격·보행 확대본을 검토

논리 테스트 39개 통과, 타격 후 제자리 경직·손전등 거리·각도·벽 가림·E 시야 판정 포함
SDL 실제 렌더 픽셀로 시야 밖 완전 검정·희미한 건물 윤곽·숨은 좀비 체력/상태/표식/효과 차단 확인
자동 입력 재생에서 5타 전투·배달 성공·체력 소진 실패·재시작과 벽 뒤 소음 우회·스태미나 소진 후 재달리기 확인
실제 Windows 창 표시 확인, 사용자도 실제 키보드 Enter로 시작됨을 확인
자동 조작 도구의 SDL 입력 전달과는 구분하며, 실제 이동·공격 조작감은 아직 별도 확인 필요
