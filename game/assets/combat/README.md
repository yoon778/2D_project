# R2-FR12 전투 리소스

- 승인한 방향별 원화·분리 부품 사용. 전체 몸 회전/미러 없이 오른팔/손/방망이 관절만 변형, 왼손 택배 유지
- 앞·오른쪽: 정지384×288(96셀4×3)12장, 이동768×1152(96셀8×12)96장. 각 셀 피벗(48,80)·기준신체64·정수2배nearest
- 나머지7방향: 정지288×192/6장·이동768×576/48장씩 유지. 전체 정지54·이동432자세
- FR 경계0/.045/.09/.135/.18/.225/.27/.32/.37/.425/.48/.54/.60초. .18 타격, .54 원본 자세 복귀, .60 종료. 다른7방향은 기존6단계
- 중간 자세는 뼈 방향의 짧은 각도·길이 보간, 손/방망이의 짧은 회전 경로로 제작. 실제12/96고유·22색·alpha0/255
- 기존FR 핵심6자세×정지/8보행54셀 RGBA 보존, 최종9셀은 R1 정지/보행의(8,8) 패딩과 일치
- 양발8위상·실제 거리의 걷기 박자·1px bob 유지. 무기는 완전한 형태로 만든 뒤 몸 깊이로 부분 가림
- 임시 좀비240×80/80셀3장(alive/stunned/dead)·피벗(40,72) 유지. 기존 메타의 불투명 행으로 몸 클릭 처리
- FR/좀비 제작: `node art/player/r2a-combat-assets.cjs`, FR 이동만: 같은 명령에 `--attack-walk-only`
- 다른7방향 제작: `node art/player/r2c8-combat-assets.cjs`
- FR 검사: `node art/player/check-r2fr-smooth.cjs`, 다른7방향/보존 검사: `node art/player/check-r2c8-combat.cjs` (Sharp 환경)
- 세 제작 경로 재실행 후 전투17PNG/17메타 값 동일. 기존 도구는 다른7뷰14메타, C8 도구는 FR/좀비3메타 보존
- 상세: [FR12 검수](../../../plans/handoffs/r2fr-smooth-review.md). R1 원화/부품/메타/PNG·다른7뷰·좀비·생산 로직 보존
