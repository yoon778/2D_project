# R2-C8 전투 리소스

- 공격: 승인한 [캐릭터 원화](../../../art/player/style-studies/eight-direction-consistency/turnaround-idle-64-v3.png)의 앞·오른쪽 픽셀에서 오른팔·손·방망이를 분리해 재배치
- 좀비: 제작 도구의 사각형으로 작성한 임시 도트. alive/stunned/dead 3상태
- [제작 도구](../../../art/player/r2a-combat-assets.cjs): Sharp 환경에서 프로젝트 루트 기준 `node art/player/r2a-combat-assets.cjs`
- 공격 PNG288×192, 96셀3×2·6자세·피벗(48,80). 원본80셀을(8,8) 옮긴 기준이며 몸 배율 유지
- 좀비 PNG240×80, 80셀3장·피벗(40,72). 두 리소스 모두 기준높이64·2배 nearest·불투명/투명 픽셀 사용
- 공격 경계0/.09/.18/.27/.37/.48/.60초, 3번 자세가 타격 순간. 별도 JSON에 프레임·발점·픽킹용 좀비 불투명 행 기록
- R2-AW 이동 공격: 공격6단계×기존 앞·오른쪽 보행8위상, 별도768×576 PNG·96셀48장·피벗(48,80)·기준64·2배 nearest
- 승인한 R1 다리 부품/관절로 전체 하체를 조립하고 상체/팔/방망이는 같은1px bob. 복귀8장은 기존 보행의(8,8) 평행이동과 RGBA 일치
- 선택은 공격 경과시간과 실제 이동 거리의 기존 보행프레임 조합. 정지/벽은 기존6장, 재출발/종료 때 위상 초기화 없음
- 이동 공격만 재생성: `node art/player/r2a-combat-assets.cjs --attack-walk-only`. 기본 전체 생성도 이동 공격/메타 포함
- R2-C8: 기존 FR 정지/이동 PNG 보존, 나머지7방향의 정지6장·이동48장씩14PNG 추가. 전체 정지48·이동384자세
- 새 방향은 각 승인 원화·다리 부품에서 오른팔/손/무기만 관절 변형. 왼손 택배 유지, 뒤/왼쪽 무기는 몸 깊이로 부분 가림. 마지막9자세는 해당 R1 정지/보행과 RGBA 일치
- 새7방향 제작: `node art/player/r2c8-combat-assets.cjs`, 실제PNG 검사: `node art/player/check-r2c8-combat.cjs` (Sharp 환경). 원본부품/R1 변경 없이 재현 가능
