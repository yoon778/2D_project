## 시간 한계

장애물 없이 실제90px/s로 이동할 때의 이론값

| 항목 | 계산 | 값 |
| --- | --- | --- |
| 전체 보행 주기 | `32 / 90` | 약0.35556초 |
| 자세 한 구간 | `(32 / 8) / 90` | 약44.44ms, 실제4px |
| 1→5 접촉 위상 간격 | `16 / 90` | 약177.78ms |

- 자세 교체만으로 위 수치·착지 체류 시간은 늘어나지 않음
- 2/6 하중수용의 무릎 굽힘·골반/가슴 눌림이 짧은 구간에서도 구별되는지가 핵심
- 표시 높이128px에서 상체 높이 차이 약2px 목표·3px 상한은 시안 기준, 실제 측정 결과 아님
- 위 계산은 엔진 FPS·캡처 FPS·성능 측정 아님
- 상체 높이 수치만으로 관절 하중·체감 개선 확정 불가
