# 1주차 R1-W1 로직 보존 확인

기준일: 2026-11-05 · baseline a9723bc
기준: [무게감 보행 시안](../r1-weight-contract.md)
상태: 보존 확인·진단 기록 완료, 지휘의 에셋 연결·검수 후 사용자 비교 확인 대기

## 현재 주기와 보존 항목

- 지면 걷기 90px/s, 한 주기 32 지면 px, 실제 변위 hypot에 따른 위상 증가 유지
- 자유 이동 90px/s 기준 한 주기는 32/90 = 약 0.35556초. 8장 균등 선택의 한 구간은 약 0.04444초이며 앱의 렌더 FPS를 뜻하지 않음
- 벽 정지·슬라이딩 때는 실제 이동 거리 감소에 따라 보행도 정지하거나 느려지는 기존 처리 유지
- 방향 선택·연속 조준·충돌·32px 주기·균등 위상·프레임 조회 로직 불변

읽기 확인 명령:

```powershell
git diff a9723bc --name-only -- game/core.py game/locomotion.py game/main.py game/player_visual.py
```

실제 결과: 출력 없음, 종료 코드 0. 네 코드 파일은 baseline과 차이 없음
소스에서도 `WALK_SPEED=90.0`, `STRIDE_DISTANCE=32.0`, 기존 거리 위상·균등 프레임 선택 확인

## 포즈 교정을 먼저 선택한 이유

이동 속도 유지/감속 질문은 아직 미답변이므로 새 속도나 주기를 정하지 않음
같은 속도·같은 그림 보폭에서 주기만 늘리면 한 주기 동안 월드 이동량이 늘어 발 미끄러짐이 커질 수 있음
이번에는 높은 발 들림을 줄이고 착지·하중 수용·낮은 통과·다음 착지의 실제 자세를 구분하는 front_right 시안으로 비교
타이밍·이동 로직을 고정해 포즈 변화 자체의 영향을 지휘의 전후 렌더에서 확인하도록 함
공통 몸 root·고정 배율을 유지하며 큰 PNG 상하 이동이나 재생 지연만으로 무게감을 대신하지 않는 계약

## 검증 범위와 다음 상태

변경은 이 인계 문서 하나. 게임 코드·새 테스트·GUI·네이티브 실행·Git 변경 없음
이미 통과한 로직 검사의 입력과 코드가 같아 반복 실행하지 않음
기존 판정 통과는 새 포즈의 무게감·접지·부드러움 통과를 뜻하지 않음
새 에셋 연결 후 전체 회귀·전후 렌더·발 미끄러짐 검수는 지휘 담당, 사용자 주관적 비교는 미확인
다른 세 방향 추가 제작과 R2는 이번 범위에 없음. 후속 지시 전 추가 작업 정지
