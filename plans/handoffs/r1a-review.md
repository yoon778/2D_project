# R1-A 지휘 검수 중단 기록

기준일: 2026-11-04
상태: 사용자 컴퓨터 사용 요청으로 일시중단
사용자 2차 확인: 미실행
R1-A 지휘 1차 완료: 아직 아님

## 저장된 작업

- [지휘 실행 절차](../commander-runbook.md): 지시·보고·수정 요청·이중 검수·중간 커밋·정지 조건
- [로직 인계](r1a-logic.md): 지면 이동·벽 충돌·독립 조준·16개 논리 테스트
- [UI 인계](r1a-ui.md): 한 방향 임시 스프라이트·발점 메타·장면·11개 화면 관련 테스트·UI-01 수정
- 실행 위치: `game/main.py`, 에셋: `game/assets/player/`
- 한 방향 고정 샘플이며 4방향·보행 모션·전투·좀비·손전등·배달은 아직 구현하지 않음

## 지휘가 실제 확인한 사항

| 검수 | 확인 결과 | 근거와 범위 |
| --- | --- | --- |
| 절차 문서 독립 검토 | 보고서 작성 권한 모순 수정 | 각 담당이 자기 handoff만 작성하도록 예외 명시 |
| 전체 문법 검사 | 통과 | `.venv\Scripts\python.exe -m compileall -q game` |
| 통합 자동 검사 | 27개 통과 | `.venv\Scripts\python.exe -m unittest discover -s game/tests -v`, 종료 코드 0 |
| 렌더 캡처 3장 | 초기·벽 뒤·벽 앞 표현 검토 | `output/review/R1-A/ui-*.png`, 프로그램 위치 배치에 의한 SDL 렌더 검사 |
| Windows 네이티브 창 | 표시 확인 | 실제 1280×720 클라이언트·한 방향 캐릭터·발점·마우스 조준 좌표 표시 관찰 |
| 창 제목 | 수정 전 덮어쓰기 재현 | `get_events()`가 `Pico2D Canvas ... FPS`로 바꿈, UI-01 수정 요청 |
| UI-01 수정 | 코드 반영·담당 자체 제목 API 3/3 확인 보고 수신 | 이벤트 처리 직후 고정 제목 복원, 지휘의 수정본 재실행은 미완료 |
| 네이티브 마우스 | 목표 좌표 변화 관찰 | 발점 (480,180)에서 화면 마우스 위치에 따라 조준 좌표·각도 변경 |
| 네이티브 자동 W/D | 이동 확인 실패·원인 미확인 | 자동 입력 후 발점이 (480,180)으로 남음, 물리 키보드 미확인 |
| 포커스 복귀·Esc·닫기 | 미확인 | 사용자 중단 전에 완료하지 못함 |
| 실제 청취 | 해당 없음 | 이번 묶음에 오디오 기능 없음 |

자동 판정·SDL fixture·실제 창·네이티브 자동 입력·사용자 물리 입력을 서로 대신 통과 처리하지 않음
root가 띄운 검수 실행은 중단 후 `game/main.py` 명령의 Python 프로세스가 조회되지 않았음
사용자 컴퓨터 사용 중에는 추가 창 실행·UI 조작·재현 검사를 하지 않음

- 이번 작업은 푸시 요청이 없어 로컬 커밋만 수행

## 재개 후 지휘가 할 일

1. 사용자 재개 요청을 확인하고 현재 브랜치·변경 파일·두 담당의 정지 상태부터 확인
2. UI-01 수정본을 실제 창으로 다시 실행해 제목 유지 확인
3. W/D 자동 입력 미반응을 재현·원인 구분하고 이동 입력·해제를 검수, 실제 입력을 확인하지 못하면 미확인으로 유지
4. 벽 접근·우회·앞뒤 가림·포커스 복귀·Esc·창 닫기를 지휘 검수
5. 문제 발생 시 담당 파일에 한정해 수정 요청하고 영향 범위 재검수
6. 지휘 1차 통과 후 중간 커밋, 실행 명령과 3~5개 확인 항목을 사용자에게 인계
7. 사용자 2차 확인과 다음 진행 요청을 받은 뒤에만 R1-B 착수

재개 후 실행 명령은 프로젝트 루트에서 다음과 같음

```powershell
.\.venv\Scripts\python.exe game/main.py
```

위 명령은 인계용 기록이며 중단 중 자동 실행하지 않음
