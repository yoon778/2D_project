# R2-LV 오른쪽 보행과 위쪽 공격 검수 · 11/8 2주차

[좀비 에셋 인계](r2lv-zombie-ui.md) · [로직 인계](r2lv-logic.md) · 기준 `26ba4bd` · 수정 `c7cf0be`

- 주인공 오른쪽 조준 보행에서 방망이를 다리 뒤로 합성함. 먼쪽 발목을 화면 위로 3px 투영하고 교차 두 위상에서 가까운 발목을 앞으로 3px 조정함. 발 교대가 가려지던 2·8장에서 하단 부츠색 픽셀 3→20, 2→25로 증가. 오른쪽 이동 공격과 마지막 회수에도 같은 보행 연결 적용.
- 위쪽을 보는 좀비는 준비 4장과 회수 1장에서 몸통 가장자리의 소매·손 가림을 줄임. 5셀에서 RGB 158픽셀 변경, alpha·마스크 일치. Windows 실제 렌더의 변경도 해당 5장에 한정됨.
- Windows SDL 숨김 창에서 보행과 공격 회수 8쌍이 같은 위상·발점에서 RGBA 일치. 좀비 타격과 공격 시간 대조, 제조 재현 및 보행 윤곽 검사와 전체 테스트 164개 통과.
