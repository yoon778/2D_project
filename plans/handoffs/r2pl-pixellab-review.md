# R2-PL PixelLab 소품과 캐릭터 시안 · 11/8 2주차

- PixelLab Pro Flash의 64×64 원본 1개를 투명 여백 기준으로 31×40으로 자르고, 기존 배달원의 차콜·청회 6색으로 맞춤.
- 게임에서는 밑면 중심을 월드 `(365, 300)`에 놓고 2배인 62×80px로 표시함. 시각 장식으로 적용했으며, 벽·주인공·좀비와 같은 지면 깊이 순서를 사용함.
- Windows SDL 실제 렌더에서 크기와 배달원 앞뒤 가림을 확인함. 자동 검사 183개 통과. 비교 캡처는 `output/review/R2-PL/alley-scale-depth.png`에 있음.
- 배달원·좀비의 기존 정면 PNG를 각각 PixelLab v3 참조로 사용함. 8방향 정지 시안 비교는 `output/review/R2-PL/character-rotations.png`에 있음.
- 배달원 앞오른쪽 걷기는 PixelLab V3에서 92×92px 8프레임으로 생성함. 좌우 발 교대를 확인했으며, 일부 프레임의 상자와 방망이 구분은 기존 스프라이트보다 흐림. `player-walk-comparison.gif`의 왼쪽은 현재판, 오른쪽은 시안.
- 좀비 앞오른쪽 걷기는 Scary Walk에서 96×96px 8프레임으로 생성함. 발 교대와 앞으로 뻗는 팔이 보이며 보폭과 팔 움직임이 현재판보다 큼. `zombie-walk-comparison.gif`에서 비교 가능. 두 캐릭터는 검수용 시안.
- 2차 확인은 시작점에서 왼쪽 위 벽 모서리 옆 쓰레기통으로 이동한 뒤 앞뒤를 오가며 확인.

## R2-PLZ 좀비 앞오른쪽 보행 적용

- 승인된 Scary Walk 8장을 앞오른쪽 보행에 반영함. 기존 80×80 셀, 발점, 배율, 접지행과 팔레트를 기준으로 보정하고 실제 알파에서 클릭 마스크를 다시 계산함.
- 변경한 8셀과 마스크 외 아틀라스·메타데이터를 기준본 `3e1320c`와 대조함. Windows SDL에서 공격 후 앞오른쪽 추격 8장과 정지 복귀를 확인함. 전체 183개 검사 통과.
- 재현과 전후 비교는 `output/review/R2-PLZ/`에 있음. 실제 조작은 `Enter`로 오프닝 건너뛰기, `R` 직후 `D`+`S` 약 3초.
