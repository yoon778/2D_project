# R2-SFW 앞오른쪽 정지 공격 검수 · 11/8 2주차

[작업 규격](../r2sfw-stationary-swing-contract.md) · 기준 `2b8deb4` · 적용 `f487ae0`

에셋 채팅이 준비에서 지지발 위로 무릎을 굽히고, 골반과 어깨가 앞쪽으로 돌아간 뒤 방망이가 몸 앞을 지나 내려오는 전신 자세를 구성했다. 1차 렌더에서 발견한 명중 전 무기 겹침과 먼 대상에서 과하게 닿아 보이는 타격 자세를 두 차례 보정했다. 정지 전용 자세 데이터에서 12장을 재생성한다. 이동 공격 RGBA, 마지막 정지 자세, 다른 방향 및 판정 로직은 기준과 일치한다.

로직 채팅과 지휘가 Windows SDL 숨김 창에서 검수했다. 로직 채팅의 자동 좌클릭 재현은 12거리의 피해·경직·표시 셀을 비교했다. 지휘 재현은 실제 방망이 끝과 좀비 레이어를 각각 그려 다음 결과를 확인했다.

| 0.18초 시점 지면 거리 | 화면과 판정 |
| ---: | --- |
| 53.89px | 0.179초에 방망이 끝 분리. 0.180초에 접촉, 체력 5→4 |

재생성 `node art/player/r2sf-front-right.cjs`. `node art/r2ap8-check.cjs --front-right`와 게임 자동 테스트 183개 통과. 기존 전체 캐릭터 에셋 검사 `--player`는 작업 전부터 이전 오른쪽 보행 픽셀 기준에서 실패해 이번 검수에는 앞오른쪽 검사만 사용했다.

비교 GIF와 타격 캡처는 `output/review/R2-SFW/native-standing.gif`, `native-timing.png`. 지휘 좌표 기록은 `after/trace.json`, 분리 캡처 비교는 `contact-pixels.json`. 사용자 2차 확인에서는 최신 게임을 열어 앞오른쪽을 조준하고 정지 상태에서 좌클릭해 준비와 타격의 무게감을 확인한다.
