# R2-SF6-ARM 한 손 스윙 시안 · 2주차

기준 `cf2211e`. 앞오른쪽 정지 공격을 정지, 준비, 몸통 회전, 타격, 통과, 회수의 전신 6자세로 다시 구성한다. 정지 원본과 사선 시점, 지지발, 왼손 택배, 오른손 방망이를 기준으로 제작한다.

- 에셋 채팅은 오른쪽 어깨·팔꿈치·손목·그립의 연결과 방망이 궤적을 잡는다. 96×96px 투명 셀 6장과 셀 안 발점 `(48,80)`. 관절점을 표시한 시트와 게임 표시 배율인 2배 GIF를 제공한다.
- 로직 채팅은 기존 앱의 텍스처 로딩에서 검수 중에만 새 시트를 읽는다. 239ms·240ms에 방망이 픽셀과 좀비 실루엣, 체력·명중 표시를 대조하고 근거리, 사거리 끝, 헛스윙을 기록한다.
- GIF 프레임은 0 / 30 / 180 / 240 / 300 / 440ms에 시작하고 스윙은 660ms에 끝난다. 지휘는 실제 GIF의 지연과 6자세를 확인한 뒤 시안과 검수 기록을 커밋한다. 게임 적용은 사용자 시안 확인 이후로 둔다.

정지는 승인 원본을 사용하고 나머지 다섯 자세를 다시 그렸다. 준비부터 통과까지 팔꿈치가 단계적으로 펴지게 잡았다. 사선으로 투영한 타격 자세의 어깨–팔꿈치–손목 길이 합계는 약 9.3px에서 15.8px로 늘었다. 양손 접점과 양쪽 부츠 밑창을 대조했다. 정지 자세의 관절점만 원본 PNG 위에 추정해 표시했다. 팔과 손잡이 연결은 [MLB 한 손 스윙 드릴](https://www.mlb.com/video/lavigne-on-one-handed-swing-c2523431183)을 참고했다.

최종 시안의 GIF는 192×192px 6프레임으로 재생된다. 타격 240ms, 종료 660ms를 인코딩 결과에서 확인했다. 미리보기는 `output/review/R2-SF6-ARM-art/joint-sheet.png`와 `swing-192.gif`에 있다. 재생성 검사는 `node art/player/swing-studies/r2sf6-arm/bake.cjs --check`로 실행한다.

동일한 시안을 Windows 숨김 SDL 실행에 임시 주입했다. 239ms에는 7거리 모두 방망이가 분리됐고, 240ms에는 36·44·60·79.9px에서 접촉과 체력 5→4를 확인했다. 120·160px는 분리된 채 헛스윙, 80.1px는 화면상 겹치지만 피해가 없었다. 제품 입력 해시를 대조했다. 캡처와 결과는 `output/review/R2-SF6-ARM-logic/candidate/`에 있다.

11/9 방망이 조정. 준비에서 방망이 끝을 어깨 뒤로 올리고, 회전에서 몸통 위로 지나가며, 통과에서는 다리 바깥으로 내려가도록 세 자세를 보정했다. 손잡이 위치와 240ms 타격 셀을 기준으로 재생성하고 PNG에서 바뀐 세 셀을 확인했다. 새 시안을 임시 로딩한 Windows SDL 재검수에서 7거리의 명중·헛스윙 결과가 위와 일치했다. 비교는 `output/review/R2-SF6-ARM-bat/bat-before-after.png`, 재검수는 같은 폴더의 `candidate/summary.json`에 있다.

## 6장·8장 재생 시간 비교
