# R2-SF6 앞오른쪽 정지 공격 게임 적용 · 2주차

기준 `9a51f66`. 사용자가 고른 B안 6자세를 적용한다. 이동 입력 없이 앞오른쪽으로 공격을 시작하면 0.24초에 타격하고 0.66초에 끝난다. 다른 공격은 기존 0.18초·0.60초를 사용한다.

- 로직은 `start_attack(facing=..., stationary_front_right=...)`에서 공격 종류를 잠근다. `Attack.stationary_front_right`, `hit_time`, `duration`을 표시와 공유한다. 기존 사거리·벽·경직 규칙을 사용한다.
- 에셋·UI는 기존 정지/이동 아틀라스와 별도인 `attack_stationary_front_right` 소스에 승인된 576×96px 시트를 연결한다. 각 자세 시작은 0 / 0.03 / 0.18 / 0.24 / 0.30 / 0.44초다.
- 지휘가 현재 이동 입력을 시작 시 로직에 전달한다. 정지로 시작한 뒤 걸으면 기존 보행 자세를 사용하고, 표시 시간은 잠긴 타격 시점에 맞춘다. 이동으로 시작한 공격은 멈춰도 기존 시간을 쓴다.
- Windows SDL에서 타격 전후의 방망이와 체력, 헛스윙과 이동 공격을 대조한다. 검수와 커밋 뒤 최신 게임 창을 열어 사용자에게 인계한다.
