# R2-SF6 앞오른쪽 정지 공격 시안

기준 `d39be82` · 2주차 · 게임 반영 전 비교용

- 앞오른쪽 전신 6자세. 정지 → 무릎 굽혀 준비 → 골반과 어깨 회전 → 타격 → 관성으로 지나감 → 회수. 승인된 64px 배달원과 사선 시점, 왼손 택배, 오른손 방망이, 바닥 접점을 기준으로 잡는다.
- 에셋 채팅은 PixelLab로 자세 또는 중간 동작을 시안으로 만든 뒤 손과 장비의 연결을 정리한다. 어떤 프레임에 PixelLab 결과를 썼는지 기록한다. 96×96px 투명 셀 6장, 셀 내 발점 `(48,80)`.
- 로직 채팅은 동일 6장으로 타격 시작 180ms와 240ms를 비교한다. B안의 준비 자세만 60ms 더 표시한다. 나머지 자세의 표시는 동일하며 두 안을 같이 반복할 때는 정지 구간을 맞춘다.
- 지휘는 동일 그림, 타격 프레임 표시 시점, 시각적 일관성을 검수하고 비교 GIF와 시안 원본을 전달한다. 게임 코드와 실행 리소스는 시안 선택 뒤에 다룬다.
