# R2-SF6 앞오른쪽 정지 공격 시안

기준 `d39be82` · 2주차 · 게임 반영 전 비교용

- 앞오른쪽 전신 6자세. 정지 → 무릎 굽혀 준비 → 골반과 어깨 회전 → 타격 → 관성으로 지나감 → 회수. 승인된 64px 배달원과 사선 시점, 왼손 택배, 오른손 방망이, 바닥 접점을 기준으로 잡는다.
- 에셋 채팅은 PixelLab로 자세 또는 중간 동작을 시안으로 만든 뒤 손과 장비의 연결을 정리한다. 어떤 프레임에 PixelLab 결과를 썼는지 기록한다. 96×96px 투명 셀 6장, 셀 내 발점 `(48,80)`.
- 로직 채팅은 동일 6장으로 타격 시작 180ms와 240ms를 비교한다. B안의 준비 자세만 60ms 더 표시한다. 나머지 자세의 표시는 동일하며 두 안을 같이 반복할 때는 정지 구간을 맞춘다.
- 지휘는 동일 그림, 타격 프레임 표시 시점, 시각적 일관성을 검수하고 비교 GIF와 시안 원본을 전달한다. 게임 코드와 실행 리소스는 시안 선택 뒤에 다룬다.

## 비교 결과

- [전신 6자세 시트](../art/player/swing-studies/r2sf6/poses.png)와 [PixelLab 참고 기록](../art/player/swing-studies/r2sf6/asset-notes.md)을 추가했다. 지휘 검수에서 셀과 밑창, 손 접점, 타격과 통과의 연결을 확인했다.
- `node art/player/swing-studies/r2sf6/preview.cjs`로 `output/review/R2-SF6/timing-comparison.gif`를 생성한다. 실제 GIF를 다시 읽어 A 180ms, B 240ms에 같은 타격 자세가 표시됨을 확인했다. 타격 뒤 표시 시간은 같다. A 동작 600ms, B 동작 660ms이며 두 안이 끝난 뒤 공통 정지 450ms를 둔다.
- 게임 실행 코드와 실행 리소스의 변경은 없다. 기존 앞오른쪽 정지·이동 에셋 재생성 검사를 통과했다. 사용자가 GIF를 비교해 시안을 고르는 단계다.
