# R2-SFM 앞오른쪽 이동 스윙 · 11/7 1주차

사용자 승인 범위는 앞오른쪽 이동 공격. 기준 `db03c9c`의 새 정지 스윙과 승인된 걷기 8위상을 같은 96px 셀과 `(48,80)` 발점에서 합성함.

- UI·에셋은 정지 스윙의 상체·방망이·택배를 이동 공격에 연결함. 벨트 아래에 걷기 다리와 위상별 1px 움직임을 합성함. 최종 회수는 일반 보행 8장과 맞춤.
- 로직은 기존 경로의 실제 거리 기반 보행과 정지·이동 전환을 대조함. 0.18초 피해·0.60초 종료와 명중 표시 확인.
- 지휘는 8위상 타격과 회수, 정지↔이동 시안, Windows 재현을 검수하고 중간 커밋을 남김. 사용자 2차 확인에서 이동 중 타격과 회수의 조작감을 비교함.
