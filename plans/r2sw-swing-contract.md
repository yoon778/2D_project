# R2-SW 앞오른쪽 스윙 시안 · 11/7 1주차

사용자 피드백의 첫 대상은 주인공 스윙과 타격감. 기준 `29a659f`, 앞오른쪽에서 정지·이동 공격을 먼저 비교함.

- UI·에셋은 방망이를 뒤로 감고 어깨가 풀리며 상대 방향을 가로지르는 궤적을 다시 제작함. 준비·타격 직전·타격·통과의 키 자세를 직접 조정. 왼손 택배, 오른손 그립, 보행 8위상, 발점, 마지막 회수 연결을 비교함.
- 로직은 실제 피해가 적용된 공격을 구분하고 판정·이동·피격 시간을 대조함. 지휘는 앞오른쪽 명중에만 0.06초 시각 표시를 연결하고 실제 Windows 렌더에서 헛스윙·명중·회수를 비교함.
- 공격 0.18초 타격과 0.60초 종료를 기준으로 하고, 나머지 7방향과 좀비 모션은 비교 기준으로 둠. 사용자 2차 확인 뒤 확대 범위 결정.
