# R2-ZT 좀비 걷기와 공격 전환 · 2026-11-07

기준선 `b6a0a0f`, 실제 1주차. 재현된 25도 접근의 공격 방향 변경과 공격 종료 직후 걷기 자세 전환을 개선한다.

- 로직 채팅은 `game/combat_visual.py`와 관련 검사를 담당한다. 공격 객체별 표시 방향을 `select_facing(attack.angle, 직전 표시 방향)`으로 잠근다. 초기화 전에는 `attack.facing`을 사용한다. 판정에 쓰는 `ZombieAttack.angle`과 `CombatWorld`는 보존한다.
- UI·에셋 채팅은 좀비 복귀 두 자세를 방향 8개와 목표 걷기 자세 8개에 맞춰 제작한다. 기존 idle에서 목표 보행까지 관절/부츠가 1/3, 2/3 진행하는 두 자세다. 발점 (40,72)·80셀·2배·이진 alpha·기존 24색·팔/옷감 가림 기준을 따른다. 기존 attack 96셀 및 기존 좀비 105셀의 픽셀/발점/마스크를 보존한다.
- 기존 `r2z-zombie-20261106.png`/JSON의 상단 640×1120과 원래 프레임은 보존하고 16행을 덧붙여 640×2400으로 만든다. `facings[name].resume`은 목표 보행 인덱스 0~7 각각에 두 개 frame을 가진 배열이다. `row=14+2*walk_index+step`, step=0/1. 정확 `clip_topleft`/`foot_pivot_topleft`/`opaque_rows`를 기록한다. 기존 텍스처 47개 사용.
- 정상 종료(.80)에만 복귀 대기 상태를 건다. 발걸음 이동 거리 0이면 idle, 실제 이동 첫 4px까지 복귀 첫 장, 다음 4px까지 둘째 장, 8px부터 기존 보행이다. 목표 보행 인덱스는 이동 시작 전 위상에 8/64를 더한 값으로 고른다. 보행 위상은 실제 이동 거리로 계속 전진한다. 취소/피격/사망/새 공격/R은 복귀 상태를 지운다. 이동 시작 뒤 멈추면 idle로 돌아간다. 포커스 정지 동안 진행하지 않는다. 현재 표시 프레임을 클릭 판정에도 사용한다.
- 기존 공격 0.8초/타격 0.30초/사거리/피해/무적·걷기 속도 90px/s·주기 64px 보존. UI는 새 제조/재현 및 임시 비교 시트만 맡고, 로직은 계약에 맞춘 fixture로 먼저 검증한다. Git과 실제 Windows 검수는 지휘 담당. 동결 뒤에는 사용자 2차 확인에서 정지한다.
