기준일: 2026-11-06 · 현재 프로젝트 1주차

기간이 지나도 미완료 작업을 완료로 바꾸지 않음
다음 주에 이전 단계 보완을 하면 실제 작업 주차와 단계 ID를 함께 남겨 계획 대비 진행을 볼 수 있게 함
사용자 2차 확인 전에는 다음 묶음으로 넘어가지 않음

## 앞으로의 커밋 형식

`<type>: <실제 작업 주차>주차 <단계 ID> <한글 작업 내용>`

예:

- `feat: 1주차 R1-A 도트풍 캐릭터 적용`
- `fix: 1주차 R1-A 캐릭터 발 접지점 수정`
- `feat: 2주차 R2 방망이 타격과 좀비 경직 구현`
- `docs: 3주차 R3 감지와 소음 검수 결과 정리`

작은 검증 단위의 중간 커밋을 유지하고 한 주의 작업을 마지막 날에 한꺼번에 몰아 커밋하지 않음
각 커밋의 실제 날짜와 변경 내용을 보존함
주차별 로그를 맞추기 위해 빈 완료 커밋이나 아직 만들지 않은 기능의 완료 기록을 만들지 않음
기존 커밋은 변경하지 않고 아래 실제 기록에 주차·단계를 연결함
주차 마무리 시 실제 변경이 있는 마지막 커밋의 본문이나 이 문서에 목표·수행·검수·남은 작업을 정리함
stage·commit·push는 지휘만 담당, 푸시는 별도 업로드 요청 때 수행함
