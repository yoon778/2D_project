# 발표용 시각자료 출처와 사용 범위

기준일: 2026-11-03

모든 이미지는 기획 설명용이다. 실제 게임 화면·완성 스프라이트·정확한 조명 판정의 증거로 사용하지 않는다. 게임용 원본과 검수 이력은 [게임 리소스 출처](../../game/assets/SOURCES.md)에서 별도로 관리한다.

| 파일 | 출처와 역할 | 사용 |

| [combat-cover.png](combat-cover.png) | 이전 PPT에 사용한 내장 imagegen 콘셉트 원본을 무편집 보존. 사용자 참고 그림과 같은 골목·배달원 구도 | 두 PPT의 표지와 손전등 설명 배경 |
| [combat-character.png](combat-character.png) | 이전 PPT의 내장 imagegen 장비 콘셉트 원본을 무편집 보존. 왼손 몸 앞 택배·오른손 방망이·가슴 부착등 | 두 PPT의 장비 설명. 새 게임용 방향별 스프라이트가 아님 |

새 전투 이미지의 정확한 도구 입력과 생성 정보:

- [1차 프롬프트](combat-2_5d-20261103.prompt.txt)
- [수정 프롬프트](combat-2_5d-20261103-v2.prompt.txt)

수정본 검수: 왼팔로 몸 앞 택배를 받치고 오른손 방망이를 사용하며 두 손·가슴등·발 접지를 확인했다. 카메라와 전방 부채꼴은 개선됐으나 바닥·벽에 잔광이 있으므로 게임의 ‘빛 밖 완전 암흑’ 규격을 그대로 보여주는 마스크 도식은 아니다. 정확한 가시성·건물 차단·상체 노출은 실제 2.5D 실행본에서 별도 검증한다. 표지의 손전등 외형 역시 장비 확정용이 아니며 실제 장비 규칙은 PRD의 가슴 부착등을 따른다.

기존 표지·장비 이미지는 과거 자료에서 계승한 원본이며 당시의 정확한 프롬프트를 새로 만들어 소급 기록하지 않는다. 생성 이미지는 학교 공지의 그래픽 예외를 따르되, 게임 규칙과 시스템의 차별화를 실제 기본판으로 검증한다.
