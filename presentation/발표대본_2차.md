# Dead Route 2차 발표 대본

총 1분 30초. PPT 55초, 실제 게임 데모 35초. **대사**만 읽고 화면 지시는 촬영과 편집에 사용합니다.

## 1. 표지 (00:00–00:05)

**대사**

안녕하세요. 좀비 마을의 야간 배달 게임, 데드 루트입니다.

**화면**

표지에서 시작. 제목이 보이는 상태에서 인사.

## 2. 목차 (00:05–00:09)

**대사**

게임과 개발 진행 상황을 소개하고, 상점 왕복을 시연하겠습니다.

**화면**

목차와 오른쪽의 실제 배달 결과 화면을 함께 보여줌.

## 3. 게임 설명 (00:09–00:22)

**대사**

어두운 골목에서 택배를 배달하는 사선 시점 생존 게임입니다. 손전등과 발소리로 위험을 파악하고, 병으로 좀비를 유인하거나 배트로 대응합니다.

**화면**

실제 상점 앞 장면. 빛에 드러난 좀비와 오른쪽 위 송장의 복귀 목표가 함께 보이게 유지.

## 4. 개발 계획 대비 현재 진행 상황 (00:22–00:42)

**대사**

1차 계획에 있던 사선 이동과 근접 전투를 구현했고, 걷기와 달리기를 여덟 방향으로 늘렸습니다. 11월 말 목표였던 손전등, 좀비의 소음 반응, 배달 한 판도 구현했습니다. 제출용 ZIP을 새 폴더에 풀어 상점 왕복과 재도전을 확인했습니다.

**화면**

왼쪽은 1차 목표일과 당시 계획. 오른쪽은 11월 15일 실행본. ZIP 검수는 Windows SDL 자동 조작 기준.

## 5. 게임 기획 변경 (00:42–00:55)

**대사**

배달 계약을 네 가지로 늘렸습니다. 상점 왕복에서는 손그림 지도를 보고 안전지점까지 돌아옵니다. 좀비를 가두는 셔터와 다리를 내리는 회로 퍼즐은 다음 개발 구상입니다.

**화면**

실제 M 지도에서 상점과 초록 안전지점, 파란 경유지를 보여줌. 00:55에 게임 녹화 화면으로 전환.

## 실제 게임 데모 (00:55–01:30)

4번 상점 왕복을 처음부터 플레이해 녹화한 뒤 필요한 장면을 이어 붙입니다. 이동을 압축하고 E 진행 막대, 차량 경보음, 지도와 결과 화면을 남깁니다.

### 00:55–01:02 4번 계약과 수령

**대사**

4번 상점 왕복입니다. 거점에서 택배를 받습니다.

**화면**

숫자 4를 누른 뒤 Enter. 수령지에서 E를 0.5초 누름. 계약 선택, 수령 막대와 오른쪽 위 송장의 목표 변경을 살림.

### 01:02–01:11 차량 경보 유인

**대사**

병을 폐차에 던지면 경보를 듣고 좀비들이 모여듭니다.

**화면**

F로 병 확보. 상점 쪽에서 서쪽 폐차에 커서를 두고 ‘차량 경보 유인’ 표시가 보일 때 Q. 경보가 울리는 순간과 좀비가 이동하는 화면을 살림.

### 01:11–01:21 배달과 M 지도

**대사**

상점에 택배를 전달한 뒤 손그림 지도를 펼쳐, 우회할 골목에 경유지를 찍습니다.

**화면**

상점 앞 배송함에서 E 1초. M을 열고 동쪽 골목에 좌클릭. 초록 안전지점과 파란 경유지 번호가 보이면 M으로 닫음.

### 01:21–01:30 안전지점 복귀

**대사**

추격을 끊고 북쪽 안전지점에 도착하면 영수증에 복귀 확인 도장이 찍힙니다.

**화면**

상점 동쪽 골목으로 우회. 긴 이동은 컷 편집하고 필요하면 Enter로 종료 컷신을 건너뜀. 마지막 3초는 배달 성공과 복귀 확인 도장을 보여줌.
